# ETALVIS C Programming Problems

This repository contains my solutions to the **selfassessment C programming problems** provided as part of the C Programming course from the **ETALVIS** learning platform.

The problems were solved as part of regular practice during the course and focus on strengthening core C programming concepts through hands on problem solving.

## 📌 Purpose of this Repository
- To document my learning progress in C programming  
- To practice and reinforce fundamental concepts through problem solving  
- To serve as a reference for revising key topics in C  
- To demonstrate consistency and structured learning  

## 🛠 Topics Covered
- Basic syntax and control structures  
- Conditional statements and loops  
- Functions  
- Arrays and strings  
- Pointers  
- Structures  
- Basic problem-solving techniques  

## 📂 Repository Structure
Each file corresponds to a specific problem and contains a standalone C program with a clear and simple implementation.

## ⚠️ Disclaimer
These solutions are written for learning and practice purposes. They are intended to demonstrate understanding of concepts and may not always represent the most optimized approach.

## 📖 Learning Outcome
By solving these problems, I gained a stronger foundation in C programming and improved my logical thinking and coding discipline.
